Everything a prop firm website needs

Challenge pricing and account picker

Programs as tabs, every account size with its fee, and a "start challenge" button per account.

Rules, phase by phase

Profit target, daily loss, max drawdown, trailing drawdown, minimum days and profit split for every phase.

An FAQ that writes itself

Answers about your rules, sizes and prices come from your challenges. Add your own questions on top.

Built for phones

A phone menu, 44 px tap targets and layouts checked at 360 px and 414 px wide.

One config file

Name, logo, challenges, prices and links live in site/config.ts. Switch designs without touching it.

Static and fast

Builds to plain files. Host it on GitHub Pages, Netlify, Vercel, Cloudflare Pages or any web server.

Launch your prop firm website in three steps

  1. Get the code. Clone the repository or click "Use this template" on GitHub, then run npm install.
  2. Make it yours. Edit site/config.ts with your firm name, logo, challenges, prices and links, and replace the disclaimer in src/core/disclaimer.tsx.
  3. Publish. Set DEMO_MODE = false, run npm run build and upload the dist folder to any host. 
git clone https://github.com/PropSim-Enterprise/prop-firm-landing-page-templates.git
cd prop-firm-landing-page-templates
npm install
npm run dev

Questions about the prop firm templates

Are these prop firm landing page templates really free?

Yes. All ten templates are MIT licensed: use them for commercial prop firm websites, change anything, and keep or remove the small credit line in the footer.

Can I use the templates without PropSim?

Yes. Point the buttons at any checkout and trader dashboard in site/config.ts. PropSim is optional: it runs the checkout, challenge engine, trader terminal and payouts if you want them.

How do I add my own challenges and prices?

Edit site/config.ts: your firm name, logo, challenge sizes, prices, profit targets, drawdown limits and links. Every template reads the same file, so you can switch designs at any time.

Are the templates mobile friendly?

Yes. Every template has a phone menu, 44 px tap targets and text of at least 12 px, and is checked for horizontal overflow at 360 px and 414 px widths.

What do I need to run them?

Node.js 20 or newer. The templates use React 19, Vite and Tailwind CSS 3, and build to static files.

Is the footer disclaimer legal advice?

No. It is a neutral starting point for a firm that sells simulated evaluations. Replace it with wording your lawyer has reviewed for the countries you sell into.
